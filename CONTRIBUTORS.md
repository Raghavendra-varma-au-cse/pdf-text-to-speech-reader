# Contributors

ReadAloud uses git history as the source of truth for contributions. If you would like to
be listed here, open a pull request that adds your GitHub handle and the area you worked
on. Do not add email addresses, phone numbers, or other personal details.

- Original project: Imran Pollob (`@imranpollob`) — see `package.json` and the UI footer.
- Additional contributors: add your handle here in a PR.

Pull requests are reviewed through the repository issue tracker:
<https://github.com/imranpollob/pdf-text-to-speech-reader/pulls>
